# brAIn-llm

LLM-provider nodes for [brAIn](https://github.com/tibzejoker/brAIn).

| Node | Purpose |
|---|---|
| `llm-basic` | Generic LLM caller using @brain/core's LLMRegistry. |
| `llm-cli` | Wraps Claude / Codex / Gemini CLI agents. |

Install via the [brAIn marketplace](https://github.com/tibzejoker/brAIn-store).
